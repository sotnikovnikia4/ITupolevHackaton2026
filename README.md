# 🔒 TUPOLEV IT CHALLENGE 2026

Веб-приложение для регистрации пользователей на хакатон с возможностью рассылки писем пользователям

Проект полностью контейнеризирован для быстрого и удобного развертывания.

---

## 🛠 Технологический стек

### Backend
* **Java 21**
* **Spring Boot** — основной фреймворк приложения.
* **PostgreSQL** — реляционная база данных для надежного хранения данных.

### Frontend
* **TypeScript** — для типизированного и безопасного кода.
* **React** — библиотека для построения пользовательского интерфейса.
* **Vite** — сборщик для быстрой разработки и оптимизации.

### DevOps & Deployment
* **Docker & Docker Compose** — для оркестрации и развертывания контейнеров.
* **Nginx** (внутри контейнеров) — для обслуживания статики и проксирования.

---

## 🚀 Деплой и запуск

Для запуска проекта на сервере или локальной машине выполните следующие шаги:

### 1. Подготовка SSL сертификатов
Для обеспечения безопасности (HTTPS) необходимо наличие SSL-сертификатов.
1.  Перейдите в папку `certs` в корне проекта.
2.  Поместите туда два файла:
    * `certificate.crt` — ваш SSL сертификат.
    * `certificate.key` — приватный ключ.

### 2. Настройка окружения
1.  Создайте файл `.env` в корне проекта.
2.  Скопируйте в него содержимое из `example.env`.
3.  Заполните переменные актуальными данными (порты, доступы к БД, настройки безопасности).

### 3. Запуск контейнеров
Выполните команду для сборки и запуска проекта в фоновом режиме:

```bash
docker-compose up --build -d
